2. Objective

Create a documentation-only clarification addendum to Phase 1.3.

The addendum must resolve two editorial-model weaknesses identified during independent review:

Issue A — Classification B combines different dimensions.

The current classification system risks conflating:

- Whether an opportunity genuinely exists.
- Whether the opportunity is suitable for Scholars' initial Nigerian undergraduate audience.
- Whether applications are currently open.
- Whether an application route is verified and usable.
- Whether enough evidence exists to publish it as actionable.

These are separate questions and must not be represented by one classification.

Define independent dimensions:

1. "provider_authenticity"
2. "audience_eligibility"
3. "academic_level_fit"
4. "application_status"
5. "application_route_status"
6. "evidence_freshness"
7. "publication_disposition"

For each dimension, define its purpose, allowed states, and the evidence required to assign a state.

Do not create database columns or implement a schema. This is an editorial and conceptual specification only.

Issue B — Evidence dates are not sufficiently distinguishable.

The report and source register do not consistently distinguish between:

- When the production database record was inspected.
- When an official provider source was last checked.
- When audience eligibility was last assessed.
- When the underlying evidence was originally published.
- Whether evidence was freshly rechecked or carried forward.

Define separate date concepts and explain how they should be recorded and interpreted.

Never describe carried-forward evidence as freshly verified.

4. Publication policy

Define a clear rule for the initial Scholars Nigerian undergraduate catalogue.

At minimum:

- An authentic opportunity is not automatically eligible for publication.
- Audience eligibility and academic-level fit are separate.
- A currently open application is not automatically actionable if its application route is unresolved.
- A reachable application URL does not prove that submissions are accepted.
- An inaccessible URL does not automatically prove that the programme is closed.
- Historical opportunities must remain distinguishable from active opportunities.
- Unresolved records should be withheld from actionable listings and routed to manual review.
- Paid training programmes must not be misrepresented as scholarships.

Explain the minimum conditions a record must satisfy before receiving an actionable/open presentation.
