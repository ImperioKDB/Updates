State · semantics · exit

Open an answer. Keep the relationship explicit.

Choose a question to reveal its associated region. Only one answer stays open, and the button’s expanded state always tracks the panel.

A short, restrained opening can clarify which answer belongs to a question. The text itself remains in normal document flow, so the surrounding layout can grow without overlays.

Each native button points to a named region, updates aria-expanded, and becomes keyboard-operable by default. Closed panels are removed from assistive-technology and keyboard navigation with aria-hidden and inert.

The same state change happens immediately. The transition is presentation only; it is never required to understand the content or operate the control.

Implementation note: the panel uses a 0fr → 1fr CSS grid-row transition. No height measurement, external library, or animation of the text itself is required.
